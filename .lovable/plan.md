# שדרוג דף הצ'ק-אאוט — חוויית מובייל מעולה

## מטרה
להפוך את דף התשלום במובייל לזורם, נעים ואיכותי — פחות גלילה, פחות בלבול, יותר אמון. בלי לגעת בלוגיקה (OTP, HYP, קופונים, פיקסלים).

## השינויים

### 1. תהליך מדורג במובייל (Progressive disclosure)
- במובייל הדף יחולק ל־3 צעדים ברורים עם אינדיקטור התקדמות דביק בראש: **1. פרטים ← 2. משלוח ותשלום ← 3. סיכום ואישור**.
- כל צעד מציג רק את הכרטיס הרלוונטי; כפתור «המשך» בתחתית מאמת את השדות של הצעד לפני מעבר (ולא מגלה שגיאות רק בסוף).
- במחשב נשארת התצוגה הדו-טורית הקיימת כמו שהיא.

### 2. סיכום הזמנה מתקפל במובייל
- בראש הדף במובייל: שורת סיכום קומפקטית דביקה — תמונות מוצרים ממוזערות + סה״כ + חץ «הצג פרטים» שפותח את פירוט הפריטים והקופון (בסגנון Shop Pay).
- מונע גלילה ארוכה דרך כל הסל לפני הטופס.

### 3. שדות קלט נוחים למגע
- שדות בגובה 48px+ (h-12), פונט 16px כדי למנוע זום אוטומטי ב-iOS.
- `inputMode`/`autoComplete` נכונים: טלפון → `tel` + `autocomplete="tel"`, שם → `name`, עיר → `address-level2`, כתובת → `street-address`.
- תוויות מעל השדות (לא placeholder בלבד), הודעות שגיאה מיד מתחת לשדה עם אייקון.

### 4. בחירת משלוח/תשלום ככרטיסי מגע גדולים
- הכרטיסים הקיימים הופכים לשורה אופקית אחת של שני כפתורים גדולים במובייל עם סימון V ברור בבחירה (במקום ring עדין).
- אחרי בחירת אשראי — מופיעה שורת אמון «תשלום מאובטח בהצפנת SSL» עם אייקון מנעול; אחרי מזומן — הסבר קצר «תשלום לשליח בעת הקבלה + אימות טלפון».

### 5. בר תחתון דביק משופר
- הבר התחתון הקיים ישולב עם הניווט התחתון של האתר (כיום הוא יושב מעליו ב-bottom-14) — יוצג סה״כ + כפתור CTA גדול בגובה מלא, עם מעבר חלק בין «המשך» (צעדים 1–2) ל«אישור הזמנה / שלם עכשיו» (צעד 3).
- אזור בטוח ל-iPhone (safe-area-inset-bottom).

### 6. מיקרו-אינטראקציות ואמון
- מעברי fade/slide עדינים בין צעדים (משתמש באנימציות הקיימות של הפרויקט).
- סימון V ירוק ליד שדה טלפון מאומת (קיים — יודגש).
- שורת אמון מתחת לכפתור האחרון: מנעול + «תשלום מאובטח» + לוגו תשלום.

## קבצים
